# F1 Bayesian Predictor

A hierarchical Bayesian forecasting system that separates driver, car, and race effects using 2025 Formula 1 data and predicts Abu Dhabi Grand Prix results and championship probabilities.

## Highlights

- Collected race, qualifying, pace, reliability, weather, and driver-form data with FastF1
- Built a hierarchical Bayesian model using PyMC
- Ran 5,000 posterior simulations for the 2025 Abu Dhabi season finale
- Estimated finishing positions, race-win probabilities, and championship outcomes

## Tech Stack

Python · PyMC · FastF1 · ArviZ · Pandas · NumPy · Matplotlib
